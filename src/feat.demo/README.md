# feat.demo —— 演示数据注入

## 负责
启动时（`activation: startup`）通过 `nf.fx.run('seed', {...})` 注入演示内容：
- **90 条会话**：10 条精选（覆盖今天/昨天/星期几/日期/跨年等时间显示规则）
  + 80 条生成会话，用于验证窗口化分页与滑窗丢弃
- 12 位联系人（10 个私聊 + 2 个群聊；补齐通讯录分类 `kind` 与排序 `initial`）、
  4 条朋友圈、两个会话的聊天记录
- **全局唯一的用户资料**（头像/昵称/在线状态/seed）：会话列表顶栏、「我」页面共用这一份

## 导出
| handler | 作用 |
|---|---|
| `onStartup()` | 返回 `nf.fx.run('seed', {...})` |

## 依赖
宿主 `NfData.seed()`。插件本身不直接改任何数据，一律走宿主能力。
